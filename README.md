# Zé Aleatório

Aplicativo Android para geração de números aleatórios dentro de um range definido pelo usuário.

![Tela inicial](screenshots/tela_inicial.jpeg)
![Tela resultado](screenshots/tela_resultado.jpeg)

## Funcionalidades

- Defina o número inicial e final do range
- Gera números aleatórios com um toque na tela
- Opção de números sem repetição
- Salva automaticamente os últimos valores utilizados
- Interface com fundo animado por cores a cada novo número gerado

## Tecnologias

- Linguagem: Kotlin
- IDE: Android Studio
- Compatibilidade: Android 8.0 (Oreo) ou superior

## Como instalar

1. Baixe o arquivo `ZeAleatorio.apk` da pasta `releases/`
2. No celular, ative a opção "Instalar apps de fontes desconhecidas"
3. Abra o arquivo e instale normalmente

## Telas

- **Tela inicial:** configuração do range e opções
- **Tela de resultado:** exibe o número gerado em destaque
